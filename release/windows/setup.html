Set up Fabula

Before Fabula opens for the first time, it downloads the programs it uses to transcribe and render your videos. This takes 10 to 30 minutes, and updates reuse all of it.

  • ffmpeg, which reads and renders the video: about 200 MB
  • Python and WhisperX, which transcribe it: several GB
  • The speech model: about 3 GB with an NVIDIA graphics card, about 0.5 GB without one
