# The two worked plans, as files

`why-rockets-go-sideways.json` (vertical, 0:37) and `rocket-editor-run.json` (landscape, 1:46)
are the compose.json of the two films `examples.md` works through, with the template
renderings stripped so only the template ids and params remain — what the assistant wrote,
not what the templates drew. They are the reference copies: if a project's plan is lost, this
is what to put back; if a template changes, the readers re-expand these params anyway.

They are read, not copied. A plan is written from the sentence in front of you.
